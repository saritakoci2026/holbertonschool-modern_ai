# Linear Regression

## Description

This project contains a function that creates and returns a Linear Regression model using Scikit-learn.

## File

- `0-linear_regression.py`: Defines the `Linear_Regression()` function.

## Function

`Linear_Regression()` creates and returns an untrained `LinearRegression` model using `sklearn.linear_model`.

## Requirements

- Python 3
- Scikit-learn
